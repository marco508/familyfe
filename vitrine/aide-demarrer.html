🚀 Démarrer

Deux temps, dans cet ordre : on crée d'abord son compte personnel, puis on crée le logement — l'espace commun du foyer — ou on rejoint celui d'un proche avec son code. Comptez deux minutes.

1

Créer votre compte

L'app s'ouvre sur l'écran de connexion. Chaque personne du foyer a son propre compte : c'est lui qui porte votre nom et vos corvées.

L'onglet « Créer »

1Deux onglets en haut : Créer et Rejoindre. Restez sur Créer.
2Le nom du logement, que tout le monde verra. Seul champ vraiment obligatoire.

Vous êtes dans l'app

1L'écran Aujourd'hui s'ouvre directement. La personne qui a créé le logement porte le badge Chef.
2La barre du bas ne change plus : Aujourd'hui, Tâches, Agenda, Plus. Le code d'invitation se trouve dans Plus.
💡

Un seul logement suffit pour tout le foyer. Si deux personnes en créent un chacune, vous vous retrouvez dans deux espaces séparés qui ne se voient pas : mettez-vous d'accord sur qui crée.

3

Rejoindre avec un code

Quelqu'un a déjà créé le logement et vous a envoyé un code. Créez votre compte, puis prenez l'onglet Rejoindre au lieu de Créer.

Saisir le code

1L'onglet Rejoindre, en haut à droite.
2Le code d'invitation : 8 caractères, lettres et chiffres, sans tiret ni espace. Les minuscules sont acceptées, l'app les met en majuscules.
3Rejoindre le logement. L'entrée est immédiate : personne n'a à valider votre arrivée, et l'app s'ouvre aussitôt sur Aujourd'hui.
4

Inviter les membres

FamiLyfe ne sert à rien tout seul. Le code de votre logement se trouve dans Plus ▸ Logement, et se partage par SMS, WhatsApp ou de vive voix.
